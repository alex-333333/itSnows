# itSnows Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A click-through snow overlay for the Windows desktop with piles, a snow blower, Christmas lights and buildable snowmen, shipped as one `.exe`.

**Architecture:** A Cargo workspace. `snow-core` holds all behaviour as a pure simulation that turns per-frame inputs into a flat draw list. `snow-preview` rasterises that list to PNG on Linux for eyeballing. `itsnows` is the Windows shell: overlay window, DirectComposition + Direct2D replay of the draw list, window tracking, tray, hotkeys.

**Tech Stack:** Rust 1.97 (2021 edition), `windows` crate (latest, added with `cargo add`), `tiny-skia` + `png` (preview only), `serde` + `serde_json` (settings), GitHub Actions `windows-latest`.

**Spec:** `docs/superpowers/specs/2026-11-14-itsnows-design.md`

## Global Constraints

- Windows 10 1903+ and Windows 11, x64. Primary monitor only. No sound.
- One `.exe`, statically linked CRT, no installer, no admin rights anywhere.
- `snow-core` has **zero dependencies** and no `std::time`, OS or graphics calls. All randomness comes from its own seeded RNG.
- All coordinates are physical pixels, origin top-left, y down. Colours are straight (non-premultiplied) RGBA `f32` in 0..=1.
- Outside play mode the overlay never takes a click, a key, or focus.
- `itsnows` must compile on Linux too (`fn main` prints "Windows only" there) so its pure modules are unit-tested here. Every Windows module is behind `#[cfg(windows)]`.
- Before each commit: `cargo test --workspace` passes, and from Task 3 on `cargo check -p itsnows --target x86_64-pc-windows-msvc` passes.
- Commit messages end with the session attribution trailer; push to `claude/zen-hypatia-7qa45s` only.

## Review Focus

Inputs the spec implies but does not spell out, most likely first. Each has a test in the task named.

1. **Huge `dt`** after sleep/resume or a stalled frame (e.g. 30 s): the world advances as if 0.1 s passed; no flake burst, no NaN. → Task 1.
2. **Degenerate windows**: zero-width, fully off-screen, negative coordinates, hundreds of windows: no panic; segments under 8 px are dropped. → Task 6.
3. **No surfaces or a zero-size screen** (display off, RDP disconnect): `step` and `draw` are no-ops, no division by zero. → Tasks 1 and 7.
4. **Corrupt, partial or older `settings.json`**: fall back to defaults per field, never crash, never refuse to start. → Task 4.
5. **Resolution change mid-run**: ground pile is resampled to the new width, flakes outside the new bounds are dropped; graphics are rebuilt on `WM_DISPLAYCHANGE` and on device loss. → Task 7 (core), Task 3 (app, manual check).

```rust
#[derive(Clone, Copy, Debug, PartialEq)] pub struct Rgba { pub r: f32, pub g: f32, pub b: f32, pub a: f32 }
#[derive(Clone, Debug, PartialEq)]
pub enum Prim {

#[derive(Clone, Copy, PartialEq, Debug)] pub enum Layer { Far, Mid, Near }
pub struct Flake { pub x: f32, pub y: f32, pub vx: f32, pub vy: f32, pub r: f32, pub layer: Layer, pub phase: f32 }
// world.rs
#[derive(Clone, Copy, PartialEq, Debug)] pub enum LightsMode { Off, ScreenTop, Windows }
#[derive(Clone, Copy, PartialEq, Debug)] pub enum LightsPattern { Steady, Twinkle, Chase }
#[derive(Clone, Debug)] pub struct Settings { pub intensity: f32, pub lights_mode: LightsMode, pub lights_pattern: LightsPattern }

#[derive(Clone, Debug)] pub struct SurfaceIn { pub id: u64, pub x0: f32, pub x1: f32, pub y: f32, pub kind: SurfaceKind, pub visible: Vec<(f32, f32)> } // visible = absolute x intervals
#[derive(Clone, Copy, Debug)] pub struct Pointer { pub x: f32, pub y: f32, pub left: bool, pub right: bool }
pub struct FrameInput<'a> { pub dt: f32, pub width: f32, pub height: f32, pub surfaces: &'a [SurfaceIn], pub settings: &'a Settings, pub pointer: Option<Pointer> } // Some = play mode
#[derive(Clone, Copy, Debug, Default)] pub struct StepOutput { pub idle: bool, pub exit_play: bool }
pub struct World; impl World {
    pub fn new(seed: u64) -> Self;
    pub fn step(&mut self, input: &FrameInput) -> StepOutput;
    pub fn draw(&self, out: &mut Vec<Prim>);          // appends, back to front

}
```

Pinned values: flake target = `1500 × intensity × (w×h)/(1920×1080)`; spawn rate = target / 4 s; layer mix 50 % Far / 30 % Mid / 20 % Near; radius Far 1.0–1.5, Mid 1.5–2.5, Near 2.5–4.0 px; fall speed Far 30–50, Mid 50–90, Near 90–140 px/s; alpha 0.5 / 0.75 / 1.0; colour white. Flakes spawn at `y = -r`, uniform x over `[-100, w+100]`. Sway: `vx += 12·sin(phase + t·1.3)` scaled by layer (0.4/0.7/1.0). Gust: starts every 8–20 s, lasts 3–6 s, ramps in and out, peak ±80 px/s for Near (same layer scale). A flake is removed when `y > height + r` or `x` leaves `[-150, w+150]`. `idle` is true when intensity is 0 and no flakes remain (later tasks add their own conditions).

### Task 5: Height maps

**Files:** Create `crates/snow-core/src/pile.rs`.

**Interfaces — Produces:**

```rust
pub const COL_W: f32 = 4.0;
pub struct HeightMap { /* x0, columns: Vec<f32>, cap */ }
impl HeightMap {
    pub fn new(x0: f32, x1: f32, cap: f32) -> Self;            // ceil((x1-x0)/COL_W) columns, min 0
    pub fn x0(&self) -> f32; pub fn x1(&self) -> f32; pub fn len(&self) -> usize;
    pub fn height_at(&self, x: f32) -> f32;                    // 0 outside
    pub fn deposit(&mut self, x: f32, area: f32) -> f32;       // adds area/COL_W to the column; returns area that did NOT fit under cap
    pub fn take(&mut self, xa: f32, xb: f32, fraction: f32) -> f32; // removes fraction of each column in range; returns area removed
    pub fn relax(&mut self, dt: f32);
    pub fn melt(&mut self, dt: f32, rate: f32);                // lowers every column by rate*dt, floor 0
    pub fn total_area(&self) -> f32; pub fn mean_height(&self) -> f32; pub fn is_empty(&self) -> bool;
    pub fn resample(&mut self, x0: f32, x1: f32);              // keeps heights by absolute x; new columns start at 0
    pub fn outline(&self, base_y: f32) -> Vec<(f32, f32)>;     // closed polygon, empty if is_empty()
}
```

Relax rule: 30 passes per second of simulated time; in each pass, for every adjacent pair whose height difference exceeds 3 px, move half of the excess from the higher to the lower. Edge columns do not spill (overflow is handled by the caller through `deposit`'s return value). `relax` conserves `total_area`.

### Task 6: Visible window-top segments

**Files:** Create `crates/snow-core/src/occlusion.rs`.

**Interfaces — Produces:**

```rust
#[derive(Clone, Copy, Debug, PartialEq)] pub struct WinRect { pub id: u64, pub left: f32, pub top: f32, pub right: f32, pub bottom: f32 }
pub const MIN_SEGMENT: f32 = 8.0;
/// `windows` is front-to-back. Returns one WindowTop SurfaceIn per window whose top edge has any visible part,
/// with `visible` = the sub-intervals not covered by windows in front and inside the screen.
pub fn window_top_surfaces(windows: &[WinRect], screen_w: f32, screen_h: f32, ground_y: f32) -> Vec<SurfaceIn>;
```

A point on a top edge is covered when a window in front contains it (`left <= x < right`, `top <= y < bottom` with `y = top` of the back window). Tops with `top <= 0` or `top >= ground_y` give no surface. Intervals narrower than `MIN_SEGMENT` are dropped; a window left with none is omitted.

```rust
    pub fn ground(&self) -> Option<&HeightMap>;          // the Ground surface's pile
}
pub const DEPOSIT_AREA: f32 = 6.0; pub const WINDOW_CAP: f32 = 24.0; pub const GROUND_CAP: f32 = 90.0;
pub const WINDOW_LAND_CHANCE: f32 = 0.5; pub const MELT_RATE: f32 = 0.2;
```

Rules:
- At most one `Ground` surface is used (the first); others of that kind are ignored.
- A flake lands when its bottom crosses `surface.y - height_at(x)` going down, `x` is inside a `visible` interval, and: on `Ground`, always; on `WindowTop`, only `Layer::Near` and only if `rng.chance(WINDOW_LAND_CHANCE)` (decided once per flake per surface). Landing deposits `DEPOSIT_AREA` and removes the flake. Check surfaces top-most `y` first.
- Overflow returned by `deposit` on a `WindowTop` respawns as one Near flake at the nearer end of the segment, already falling. On `Ground` it is discarded.
- Reconcile each step by `id`: new id → empty pile. Missing id → pile dropped and its snow shaken off. Changed `x0`, `x1` or `y` → shaken off, pile reset to the new span. Unchanged geometry but a column now outside `visible` → that column's snow is shaken off. The `Ground` surface is never shaken off: it is `resample`d when its span changes.
- Shake-off: for each affected column emit `ceil(area / DEPOSIT_AREA)` Near flakes (max 400 per surface per step) at the column's x, at the old pile surface height, with small random `vx`.
- `relax` every step; `melt(dt, MELT_RATE)` only while intensity is 0.
- Draw order: far flakes, mid flakes, piles (`Polygon` from `outline`, colour `(0.96,0.98,1,1)`), near flakes.
- `idle` additionally requires nothing to be melting (all piles empty, or intensity > 0 is already non-idle).
- Screen size change: flakes outside the new bounds are removed.

## Milestone 5 — play mode

### Task 11: Snowballs and snowmen (core)

**Files:** Create `crates/snow-core/src/play.rs`; modify `world.rs`; preview scene `snowman`.

**Interfaces — Produces:**

```rust
impl World { pub fn ball_count(&self) -> usize; pub fn snowman_count(&self) -> usize; }
pub const PLAY_TIMEOUT: f32 = 30.0; pub const BALL_MIN_R: f32 = 6.0; pub const BALL_MAX_R: f32 = 60.0;
pub const THROW_SPEED: f32 = 600.0; pub const GRAVITY: f32 = 1200.0;
```

Rules (all on the Ground surface; play input exists only when `FrameInput.pointer` is `Some`):
- **Timeout:** time since the pointer last moved or changed a button accumulates while `pointer` is `Some`; at `PLAY_TIMEOUT`, `StepOutput.exit_play = true`. It resets when `pointer` becomes `None`.
- **Border:** while `pointer` is `Some`, draw a frosty frame: four `RoundRect`s, 3 px, colour `(0.7,0.9,1,0.8)`, last in the draw list.
- **Roll:** on left press within 30 px above the ground pile surface (or on it), with no ball under the pointer, a ball starts with area 0. While held, the ball's x follows the pointer; for the columns the ball's centre passed over since the last step, `ground.take(xa, xb, 1.0)` is added to the ball's area. `r = sqrt(area/π)`, capped at `BALL_MAX_R` (once capped it takes no more snow). The ball rests on the pile surface. If released with `r < BALL_MIN_R`, its area is deposited back and it vanishes.
- **Grab:** left press on an existing free ball picks it up; while held it follows the pointer in x and y.
- **Drop / stack:** on release with pointer speed < `THROW_SPEED`: if the ball's centre x is within the radius of a top ball of a stack (or a lone ball) and the dropped ball is strictly smaller than it and the stack has fewer than 3, it sits centred on top. Otherwise it lands on the ground at that x; if that overlaps another ball it is placed beside it.
- **Snowman:** a stack reaching 3 balls becomes a snowman: fixed, drawn with coal eyes and buttons (dark `Circle`s), a carrot nose (orange `Polygon`), twig arms (`Line`s) and a hat (dark `RoundRect`s) or a scarf (red `RoundRect`), chosen by the RNG.
- **Throw:** on release with pointer speed ≥ `THROW_SPEED` (speed measured over the last 0.1 s), the ball flies with that velocity under `GRAVITY`. When it crosses any surface's pile line, hits the ground line, or leaves the screen, it bursts into `min(200, ceil(area / DEPOSIT_AREA))` Near flakes with random outward velocities.
- **Crumble:** right press on a free ball, stack, or snowman deposits its total area back into the ground columns beneath it (spread evenly across its width; overflow discarded) and removes it.
- Balls are white `Circle`s with a slightly blue 1 px offset shadow circle beneath. Draw order: after piles and blower, before near flakes.
- Balls and snowmen persist when `pointer` is `None`. `clear_snow` leaves them. The blower ignores them (it takes snow from columns behind them as normal).
